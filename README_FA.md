# LinkPilot Browser — نسخه اولیه منبع

این بسته یک اسکلت اولیه اندروید برای مرورگر LinkPilot است.

## امکاناتی که در این نمونه پیاده شده‌اند
- مرورگر مبتنی بر Android WebView (موتور Chromium سیستم)
- نوار آدرس و بازکردن صفحات
- مدیریت ساده تب‌ها
- منوی نگه‌داشتن روی لینک
- کپی لینک و بازکردن لینک در تب جدید
- پنجره ترجمه Google Translate برای عنوان لینک
- مدیریت دستورهای سفارشی
- حفظ دقیق متن ابتدایی/انتهایی: هیچ `trim` یا نرمال‌سازی روی آن‌ها انجام نمی‌شود.

## محدودیت مهم این نسخه
ارسال مستقیم به تلگرام هنوز پیاده‌سازی نشده است. این قابلیت باید با MTProto/TDLib و ورود امن حساب کاربری تکمیل شود. در این نسخه، انتخاب دستور فقط خروجی دقیق را در کلیپ‌بورد قرار می‌دهد و پیام موفقیت ارسال نمی‌کند. این کار عمداً انجام شده تا ارسال تلگرام را به‌اشتباه شبیه‌سازی نکنیم.

## ساخت APK
1. Android Studio را نصب کن.
2. پوشه پروژه را باز کن.
3. اجازه بده Gradle همگام‌سازی شود.
4. SDK پلتفرم Android 35 و JDK 17 را نصب کن.
5. از منوی Build گزینه Build APK(s) را بزن.

حداقل نسخه اندروید: Android 11 (API 30).

## تکمیل اتصال تلگرام
برای اتصال حساب شخصی باید API ID و API Hash خودت را از `my.telegram.org` بسازی و در برنامه وارد کنی. این مقادیر و کد ورود را در چت برای کسی ارسال نکن. مرحله بعدی توسعه، اضافه‌کردن TDLib، ورود با کد/رمز دومرحله‌ای و ارسال MTProto به `@V2TGbot` است.


## ساخت APK بدون کامپیوتر (از طریق GitHub Actions)
1. در گوشی وارد github.com شو و یک حساب بساز/وارد شو.
2. یک مخزن جدید (New repository) با نام `LinkPilotBrowser` بساز.
3. فایل ZIP سورس را استخراج کن و فایل‌ها را در مخزن بارگذاری کن؛ پوشه مخفی `.github/workflows` نیز باید بارگذاری شود.
4. از زبانه Actions، گردش کار `Build LinkPilot APK` را اجرا کن یا منتظر اجرای خودکار پس از push بمان.
5. پس از سبز شدن اجرای workflow، وارد همان اجرا شو، در بخش Artifacts فایل `LinkPilot-debug-apk` را دانلود کن و APK را روی گوشی نصب کن.

توجه: این APK نسخه آزمایشی است و ارسال مستقیم تلگرام در آن هنوز فعال نیست؛ گزینه‌های دستور در این نمونه فقط متن ساخته‌شده را کپی می‌کنند. برای ارسال واقعی باید اتصال امن MTProto/TDLib جداگانه تکمیل و آزمایش شود.
