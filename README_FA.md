# Mili Chrome — نسخه آزمایشی

این پروژه یک مرورگر اندرویدی مستقل مبتنی بر Android WebView (موتور Chromium ارائه‌شده توسط اندروید) است.

## ساخت APK

در GitHub Actions، workflow با نام **Build Mili Chrome APK** را اجرا کنید. فایل خروجی در Artifact با نام `Mili-Chrome-debug-apk` قرار می‌گیرد.

## قابلیت‌های موجود در این نسخه

- رابط اولیه مشکی/قرمز با نام Mili Chrome
- نوار نشانی و جستجو، عقب/جلو و بارگذاری مجدد
- تب‌های پس‌زمینه برای لینک‌ها: ایجاد تب فقط URL را ذخیره می‌کند؛ WebView ساخته نمی‌شود و درخواست شبکه‌ای تا انتخاب تب آغاز نمی‌شود
- منوی لمس طولانی لینک: بازکردن در تب پس‌زمینه، کپی و ترجمه عنوان واقعی لینک
- گزینه ترجمه در نوار انتخاب متن اندروید
- پنجره ترجمه Google
- مسدودسازی ابتدایی برخی دامنه‌های تبلیغاتی در لایه درخواست شبکه
- تنظیم آدرس ربات مقصد در تنظیمات

## مواردی که هنوز تکمیل نشده‌اند

- ارسال واقعی پیام از حساب شخصی تلگرام به ربات با TDLib و ورود امن
- موتور افزونه‌های Chrome و پشتیبانی از افزونه‌های فروشگاه Chrome؛ فیلتر تبلیغات فعلی یک مسدودکننده پایه است، نه سیستم افزونه کامل
- مدیریت کامل دستورهای سفارشی و ویرایش الگوها
- آیکون نهایی برند و رابط کاربری کامل در حد Chrome

این پروژه عمداً قابلیت‌های تکمیل‌نشده را به‌عنوان قابلیت آماده معرفی نمی‌کند.
