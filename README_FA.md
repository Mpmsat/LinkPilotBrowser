# Mili Chrome — پروژه مرورگر اندروید

این پروژه یک مرورگر مستقل اندروید با رابط مشکی/قرمز و موتور `Android System WebView` (مبتنی بر Chromium نصب‌شده روی دستگاه) است. این برنامه خود Google Chrome نیست و موتور اختصاصی Chrome را داخل APK بسته‌بندی نمی‌کند.

## ساخت APK با GitHub Actions

1. تمام محتویات این پوشه را در ریشه مخزن GitHub قرار بده.
2. به بخش Actions برو.
3. workflow با نام **Build Mili Chrome APK** را اجرا کن.
4. پس از موفقیت، Artifact با نام `Mili-Chrome-debug-apk` را دانلود و APK را روی گوشی نصب کن.

## قابلیت‌های پیاده‌سازی‌شده

- نوار نشانی/جستجو با جستجوی Google، عقب، جلو، خانه و بارگذاری مجدد
- مدیریت تب‌ها؛ تب لینک پس‌زمینه فقط URL را نگه می‌دارد و تا زمان انتخاب، WebView یا درخواست شبکه ایجاد نمی‌کند
- منوی لمس طولانی لینک: بازکردن پس‌زمینه، بازکردن همین تب، کپی، ترجمه عنوان واقعی و انتخاب دستور تلگرام
- چهار دستور پیش‌فرض `/ql`، `/jl`، `/l` و `/yl`
- افزودن، ویرایش، حذف، فعال/غیرفعال‌کردن دستورها و تعیین نام، prefix، suffix، template و ربات مقصد
- حفظ دقیق فاصله‌ها و newlineهای prefix/suffix در ساخت متن دستور؛ هیچ trim روی این فیلدها انجام نمی‌شود
- بازکردن گفت‌وگوی ربات تلگرام با متن آماده‌شده؛ کاربر ارسال نهایی را در تلگرام تأیید می‌کند
- نشانک‌ها، تاریخچه و دانلودها
- جستجو در صفحه
- مسدودسازی پایه برخی دامنه‌های تبلیغاتی و امکان استثنا کردن سایت فعلی
- تنظیم صفحه اصلی و نام کاربری ربات مقصد
- ترجمه متن انتخاب‌شده از منوی زمینه و پنجره Google Translate

## محدودیت‌های شفاف

- **ارسال خودکار و بی‌نیاز از تأیید به‌عنوان حساب شخصی تلگرام پیاده‌سازی نشده است.** این نسخه لینک گفت‌وگوی ربات را با متن آماده باز می‌کند؛ کاربر باید دکمه ارسال را در Telegram بزند. ارسال مستقیم واقعی به TDLib، ورود امن و آزمایش مستقل نیاز دارد.
- مرورگر از WebView سیستم استفاده می‌کند؛ تضمین برابری کامل با Google Chrome، پشتیبانی از تمام افزونه‌های Chrome، یا رفتار یکسان در همه وب‌سایت‌ها وجود ندارد.
- مسدودکننده تبلیغات فهرست پایه دامنه‌هاست، نه موتور کامل افزونه‌ها یا فیلترهای uBlock Origin.
- گزینه ترجمه انتخاب متن از منوی زمینه WebView ارائه شده است؛ ظاهر و محل آن ممکن است با منوی شناور نسخه‌های مختلف اندروید تفاوت داشته باشد.
